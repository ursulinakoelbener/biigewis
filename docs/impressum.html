Hosting und Datenschutz

Diese Website wird als GitHub Page gehostet. Beim Aufruf verarbeitet der Hoster technisch notwendige Daten, insbesondere die IP-Adresse der Besucherinnen und Besucher. Die Server befinden sich möglicherweise ausserhalb der Schweiz, auch in den USA.

Für Gestaltung und Grafiken werden Dateien von externen Servern geladen: das Stylesheet Tufte CSS (von GitHub Pages) und die Bibliothek D3 (von d3js.org). Dabei wird ebenfalls die IP-Adresse an diese Server übermittelt.

Diese Website setzt keine Cookies ein und verwendet keine Analyse- oder Tracking-Dienste. Wer mir eine E-Mail schreibt, dessen Angaben verwende ich nur, um die Nachricht zu beantworten.
